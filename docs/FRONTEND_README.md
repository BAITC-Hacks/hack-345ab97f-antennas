# Tyńda frontend

Интерфейс подключён к FastAPI бэкенду. По умолчанию работает live режим: каталог,
история, текстовые и голосовые реплики идут на сервер. Для изолированной демонстрации
можно задать `VITE_DEMO_MODE=true`; тогда используются только данные браузера.

## Запуск вместе с backend

В корне репозитория заполните `.env` по `.env.example`, как минимум `LLM_API_KEY`
и `LLM_MODEL`, затем выполните `docker compose up --build`. Откройте
`http://localhost:5173/call`. Backend доступен по `http://localhost:8000`.

Без Docker: запустите `make run` для backend, затем `cd frontend`, `npm ci`,
`npm run dev`. Адреса можно переопределить через `frontend/.env`:

```dotenv
VITE_DEMO_MODE=false
VITE_API_URL=http://localhost:8000
VITE_WS_URL=ws://localhost:8000/ws
```

Изменения переменных Vite требуют перезапуска frontend. При запуске на другом
компьютере задайте адрес backend, доступный **браузеру**, а не имя Docker-сервиса.

## Звонок

Текст отправляется через `POST /calls/{id}/turns`; WebSocket показывает статус,
транскрипт, решение и ответ. История и каталог читаются с backend. В редакторе
каталога новое описание становится доступно LLM-роутеру для следующей реплики.

Кнопка «Начать звонок» запрашивает микрофон. «Отправить запись» кодирует реплику
в PCM16 mono 16 кГц, отправляет `audio_chunk` и `speech_end` по WebSocket и ждёт
событие `dialog`. Максимальная длина записи — 30 секунд. Для распознавания
установите `STT_PROVIDER=openai` в корневом `.env`. Для голосового ответа установите
`TTS_PROVIDER=openai`; браузер воспроизводит полученный WAV. Если микрофон или
голосовой провайдер недоступны, текстовый ввод остаётся рабочим.

Трассировка отображает только этапы, измеренные сервером. Для текстовой реплики
нет `stt`, а при выключенном TTS нет `firstAudio`. `playback` браузера сервер не
измеряет.

## Проверка

В `frontend/`: `npm run build`, `npm run lint`, `npm test`.
Для live проверки отправьте текст «Я оплатил страховку, но полис не пришёл» и
откройте появившуюся трассировку. Ответ LLM требует действующий API-ключ;
demo mode работает без него.
