## Если подключён рабочий Gateway

Параметр: ?gateway=ws://localhost:8000/ws. Дождитесь gateway online, затем используйте микрофон или поле произвольного текста. Проверьте обновление каталога по catalog_updated. Не обещайте голосовой ответ: воспроизведение tts_audio ещё не реализовано в этом пакете.

Без Gateway поле текста проверяет только соединение OpenAI через proxy. Оно не возвращает структурированный маршрут.

## Резервный показ

При отказе Gateway перейдите к кнопкам демо и явно объявите переключение на заранее подготовленные результаты. При отказе микрофона используйте поле текста при работающем Gateway. Не имитируйте выполненные бизнес-действия или передачу оператору.

Если видео действительно записано и проверено, можно показать его офлайн. Инструкция записи — VIDEO_BACKUP.md; готового MP4 в пакете нет.
