# Проверка перед коммитом

Дата: 2026-09-23.

- node --check: app.js, gateway.js, server.mjs — без синтаксических ошибок.
- node --test: 12 автономных тестов — успешно. Реальный ключ и платные API не используются.
- Браузер: Chromium/Edge, 1440×1000 и 390×844 — четыре экрана доступны, горизонтального переполнения нет.
- Демо/clarify: структурированный JSON, null scenario_id при уточнении, альтернативы и водопад с последовательными смещениями.
- Ошибка отсутствующего ключа и отмена позднего API-ответа при выборе демо — проверены.
- Каталог: переименование без дубликата, запрет занятого ID, восстановление после перезагрузки — проверены.
- CSV: файл истории сессии скачивается; синтетические записи помечены demo.
- Неизвестный hash возвращает экран звонка. Ошибок JavaScript в проверенных переходах нет.

Не проверено: реальный вызов OpenAI новым ключом, STT/TTS и полный голосовой цикл с production Gateway. Микрофон пользователя в автотестах не включался. Видео ещё не записано.
