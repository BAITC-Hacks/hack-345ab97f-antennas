# Готовность frontend-пакета

| Область | Реализовано | Ещё требуется |
|---|---|---|
| Звонок | ru/kk/mixed/clarify; текст через локальный Gateway | Проверка реального LLM новым ключом |
| Микрофон | PCM16 mono 16 kHz, RMS VAD, освобождение микрофона | Проверка с STT в live-интеграции |
| Трассировка | JSON, причина, альтернативы, intent list, последовательный водопад | Реальные измерения и корреляция concurrent turns |
| Супервизор | Серверные traces, метрики, CSV, локальные карточки | Holdout eval и связь с контакт-центром |
| Каталог | Серверные CRUD/версии/JSON-персистентность; offline localStorage | Production-хранилище и авторизация |
| OpenAI | Structured router, STT/TTS-адаптеры, аудиоплеер; отдельный smoke-test proxy | Новый ключ и проверка реального вызова |
| Материалы | README, 7 слайдов, демо-скрипт, инструкция записи, черновики сообщений | Запись MP4 и согласование с организаторами |

Демо-данные не доказывают accuracy, задержку или качество казахского STT.
Добавлен соседний [backend](../voice-router-backend/README.md): WebSocket, серверный каталог/история, метрики, локальная очередь карточек, OpenAI-адаптеры. Frontend воспроизводит tts_audio, загружает серверный каталог и умеет удалять записи после подтверждения. Полная проверка в браузере пройдена в demo-режиме; реальные платные API-вызовы ещё не выполнены.
Слайды и PROJECT_README описывают целевую архитектуру — их утверждения нужно сверить после интеграции.

Перед сдачей: подключить Gateway, выполнить реальный eval, проверить голосовой цикл, подтвердить обновление каталога, записать видео и проверить запуск на чистом ноутбуке.
