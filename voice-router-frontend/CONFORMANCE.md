# Готовность frontend-пакета

| Область | Реализовано | Ещё требуется |
|---|---|---|
| Звонок | Готовые ru/kk/mixed/clarify; текстовый ввод | Реальная маршрутизация в Gateway |
| Микрофон | PCM16 mono 16 kHz, RMS VAD, освобождение микрофона | Проверка с STT в live-интеграции |
| Трассировка | JSON, причина, альтернативы, intent list, последовательный водопад | Реальные измерения и корреляция concurrent turns |
| Супервизор | Синтетические KPI, история, CSV | Trace Store/eval, реальная очередь операторов |
| Каталог | Создание, проверка ID, редактирование, localStorage | Серверный каталог; удаление пока локальное |
| OpenAI | Серверный smoke-test proxy, ошибки, закрытый .env | Новый ключ и проверка реального вызова |
| Материалы | README, 7 слайдов, демо-скрипт, инструкция записи, черновики сообщений | Запись MP4 и согласование с организаторами |

Демо-данные не доказывают accuracy, задержку или качество казахского STT.
tts_audio сейчас отображается в журнале, но не воспроизводится.
Слайды и PROJECT_README описывают целевую архитектуру — их утверждения нужно сверить после интеграции.

Перед сдачей: подключить Gateway, выполнить реальный eval, проверить голосовой цикл, подтвердить обновление каталога, записать видео и проверить запуск на чистом ноутбуке.
