### Быстрый запуск frontend

```bash
cd frontend
npm ci
npm run dev
```

Откройте http://localhost:5173/call. По умолчанию включён demo mode: backend для показа не требуется. Реальная база данных и backend в этом репозитории пока не реализованы; [план подключения](database/README.md).
